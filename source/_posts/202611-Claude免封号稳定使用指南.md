## 一、原理先说清

Claude 封号不是随机抽奖，它看的是「这台机器像不像一个正常的当地用户」。

所以稳定使用的核心不是找什么黑科技，而是把这几件事做一致：**IP 干净且独享、时区语言和 IP 国别对得上、整机流量都从那条线出去、一个账号只在一台机器上用**。

## 二、六步走

**第一步：先测环境，全绿再去登录**

打开 `ip.net.coffee/claude`，它会把出口 IP、信任分、IP 属性、DNS 泄露、WebRTC 泄露一次列出来。红绿一眼就能看懂。

![Claude IP 检测页](/images/261110-5.png)

顺序很重要：**先全绿，再访问 claude.ai**。每次重启电脑都先测一遍。

**第二步：租一台海外 VPS 当专属出口**

不要用公共机场或共享节点——同一个 IP 上有人被封，你容易被连坐。自己租一台最便宜的海外机器，全机流量都走它。

**第三步：把 VPS 变成代理节点**

SSH 上去，用一键脚本装好代理服务，会给你一条节点链接，复制保存。

**第四步：本地用 TUN 模式**

客户端里一定要开「虚拟网卡 / TUN 模式」。只开系统代理的话，命令行工具不读系统代理，流量会漏——Claude Code 这种就是典型。

**第五步：补齐一致性**

- 关掉 IPv6（挂了代理 v6 还在直连，最容易露馅）
- 时区改成和服务器一致
- DNS 用同一个出口
- 浏览器语言只留英文

改完刷新检测页，除了「机房 IP」这一项，其他都应该是绿的。

**第六步：注册和订阅**

用干净环境打开 claude.ai 登录页，IP 够干净时不会弹验证码。订阅走应用商店改区，绑一张能付外币的卡。

## 三、长期用的几条经验

- **一号一机**：别来回切号、别在同一台机器上挂好几个号；
- **别混着用**：同一个环境里不要一边登官方、一边接中转站，行为特征会很怪；
- **额度留余量**：别天天顶满，正常人有起伏；
- **新号先养**：前几天正常聊天，别一上来就猛跑 CLI。

## 四、说句实在话

这套东西能显著降低风险，但没有「绝对不封」。所以真正重要的东西不要只压在一个号上，该备份的备份，该有替代方案的有替代方案。
