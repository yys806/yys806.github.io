## 一、先把原理说清

Claude 判断「这个账号正不正常」，看的不是你说什么，而是这台机器像不像一个正常的当地用户。

核心就四件事：**IP 干净且独享、时区语言 DNS 和 IP 国别对得上、整机流量都从那条线出去、一个账号只在一台机器上用**。

下面按顺序做，每一步都有可以直接复制的命令或链接。

## 二、第一步：测环境，全绿再登录

打开这个检测页：

👉 [https://ip.net.coffee/claude/](https://ip.net.coffee/claude/)

它会把出口 IP、信任分、IP 属性（住宅/机房）、DNS 泄露、WebRTC 泄露、claude.ai 可达性一次列出来，红绿一眼能看懂。

![Claude IP 检测页](/images/261110-5.webp)

**判定标准**：

- 出口 IP 只显示一个、且和美国节点一致
- DNS 泄露：未检测到
- WebRTC：未检测到
- 信任分：良好以上
- 「机房 IP」这一项红了可以先不管，家用宽带 IP 太贵，机房 IP 是能用的

**顺序很重要**：先全绿，再去打开 claude.ai。每次重启电脑也要先测一遍。

## 三、第二步：租一台海外 VPS 当专属出口

不要用公共机场、不要用共享节点——同一个 IP 上有人被封，你容易被连坐。

选机器可以看这个测评榜：

👉 [https://digvps.com/review](https://digvps.com/review)

榜单上除了分数，还有工单速度、退款政策、是否实名、支付方式，比只看价格有用。我选的是便宜档位，地区选美国。

买完先测这个 IP 到国内的延迟，太慢就提工单换 IP。

## 四、第三步：把 VPS 变成代理节点

**1）登录服务器**

```bash
ssh root@你的服务器IP
```

第一次会让你确认指纹，输 `yes`，然后输入密码（粘贴密码时光标不动是正常的，直接回车）。

**2）先更新系统**

```bash
apt update && apt -y upgrade
```

**3）装代理服务**

用这个一键脚本：

👉 [https://github.com/233boy/sing-box](https://github.com/233boy/sing-box)

打开 README，复制里面那行安装命令，粘进终端回车。装完它会输出一条节点链接（一般以 `vless://` 开头），复制保存好。

**4）验证服务在跑**

```bash
systemctl status sing-box --no-pager
```

看到 `active (running)` 就对了。

## 五、第四步：本地用 TUN 模式

**1）把节点链接转成客户端配置**

打开 👉 [https://shipengtao.com/en/tools/vless-to-clash/](https://shipengtao.com/en/tools/vless-to-clash/)

把上一步拿到的链接粘进去，点 Convert，下载 yaml。

**2）导入客户端**

我用的客户端是 Clash Verge。下载安装后：订阅 → 新建 → 本地 → 选刚才那个 yaml → 保存 → 右键启用。

👉 [https://github.com/clash-verge-rev/clash-verge-rev/releases](https://github.com/clash-verge-rev/clash-verge-rev/releases)

**3）必须开 TUN 模式**

在客户端设置里找「虚拟网卡 / TUN 模式」，打开。

这一步不能省：只开系统代理的话，很多命令行工具根本不读系统代理，流量会漏出去——Claude Code 这类工具就是典型。

## 六、第五步：把环境补齐

打开 Windows 的「网络连接」，右键你的网卡 → 属性 → **取消勾选 `Internet 协议版本 6 (TCP/IPv6)`**。

IPv6 是最常见的漏点：挂了代理之后 IPv4 变成服务器 IP，但 IPv6 还在走本地直连，检测页上一看国别就对不上。

然后改这几项：

| 项目 | 怎么改 |
|---|---|
| 时区 | 设置 → 时间和语言 → 关闭「自动设置时区」，手动选和美国节点一致 |
| 语言 | 浏览器设置里把英文提到最上，删掉中文 |
| DNS | 浏览器安全 DNS 打开，选 Cloudflare |

改完回到第一步那个检测页刷新，除了「机房 IP」，其他都应该是绿的。

## 七、第六步：注册和订阅

**注册**：在干净环境里打开 👉 [https://claude.ai/login](https://claude.ai/login)

推荐用 Google 账号登录。IP 够干净的时候不会弹验证码，也不用手机号。

**订阅（安卓为例）**：

1. 手机先有美国网络；
2. 装 Claude 官方 App 和 Google Play；
3. Play → 头像 → 设置 → 常规 → 国家和地区改成美国；
4. Play → 付款方式 → 绑一张能付外币的信用卡；
5. 回 Claude App 里订阅 Pro。

## 八、长期用的几条规矩

- **一号一机**：别在几台电脑之间来回登同一个号；
- **别混着用**：同一个环境里不要一边登官方、一边接中转站，行为特征会很怪；
- **额度留余量**：别天天顶满，正常人的用量是有起伏的；
- **新号先养**：头几天就正常聊天，别一上来猛跑 CLI；
- **常备小号**：主力号之外养一两个备用，真出事不至于断档。

## 九、说句实在话

这套东西能显著降低风险，但没有任何方法能保证「绝对不封」。所以真正重要的东西不要只压在一个号上——该备份的备份，该有替代线路的有替代线路。
